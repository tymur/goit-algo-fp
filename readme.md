**Завдання 3**
*Реалізація*
Основні кроки програми:
 - Створення класу Graph, який зберігає вершини та ребра.
 - Додавання методів:
  - add_edge(u, v, weight) — додає ребро між вершинами u та v з вагою weight.
  - dijkstra(start) — реалізує алгоритм Дейкстри з використанням купи.
 - Збереження найкоротших шляхів у словнику distances.
