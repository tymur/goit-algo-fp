

## Завдання 3. Реалізація.

Реалізація алгоритму складається з кількох основних етапів:

1. **Створення графа**
   Граф представлено у вигляді словника суміжності, де ключем є вершина,
   а значенням — список кортежів із суміжними вершинами та вагами ребер.
   Це дозволяє ефективно зберігати зважені зв’язки між вершинами.

   ```python
   self.vertices = {
       "A": [("B", 4), ("C", 2)],
       "B": [("A", 4), ("C", 1), ("D", 5)],
       ...
   }
   ```

2. **Додавання ребер**
   Метод `add_edge(u, v, weight)` додає зв’язки між вершинами `u` та `v` з вагою `weight`.
   Для простоти реалізації використовується **неорієнтований граф**,
   тому зв’язок додається в обидва напрямки.

   ```python
   def add_edge(self, u, v, weight):
       if u not in self.vertices:
           self.vertices[u] = []
       if v not in self.vertices:
           self.vertices[v] = []
       self.vertices[u].append((v, weight))
       self.vertices[v].append((u, weight))
   ```

3. **Ініціалізація відстаней**
   Для всіх вершин початкова відстань вважається нескінченною (`float('inf')`),
   окрім початкової вершини `start`, для якої вона дорівнює `0`.

   ```python
   distances = {vertex: float('inf') for vertex in self.vertices}
   distances[start] = 0
   ```

4. **Використання бінарної купи (`heapq`)**
   Для оптимізації вибору вершини з мінімальною відстанню використовується модуль `heapq`,
   який реалізує мін-купу з часовою складністю `O(log n)` на операцію вставки або видалення.

   ```python
   import heapq
   heap = [(0, start)]  # (вага, вершина)
   ```

5. **Основний цикл алгоритму Дейкстри**
   Алгоритм працює, доки купа не порожня:

   * витягує вершину з найменшою відстанню;
   * оновлює відстані до її сусідів, якщо знайдено коротший шлях;
   * додає оновлені вершини назад у купу.

   ```python
   while heap:
       current_distance, current_vertex = heapq.heappop(heap)
       if current_vertex in visited:
           continue
       visited.add(current_vertex)

       for neighbor, weight in self.vertices[current_vertex]:
           distance = current_distance + weight
           if distance < distances[neighbor]:
               distances[neighbor] = distance
               heapq.heappush(heap, (distance, neighbor))
   ```

6. **Результат роботи алгоритму**
   Метод `dijkstra()` повертає словник із найкоротшими відстанями
   від стартової вершини до всіх інших, що дозволяє легко аналізувати результати.

   ```python
   return distances
   ```


**Особливість реалізації:**
Завдяки використанню **бінарної купи (`heapq`)**, алгоритм працює значно швидше,
ніж класична реалізація з лінійним пошуком мінімальної вершини,
що робить його придатним для **великих графів** із сотнями або тисячами вершин.

# Завдання 7. Метод Монте-Карло — моделювання кидків кубиків 🎲

## Мета
Імітувати багаторазове кидання двох кубиків, обчислити ймовірності можливих сум (від 2 до 12) методом Монте-Карло та порівняти їх з аналітичними значеннями.

---

## Методика
1. Виконано `1 000 000` кидків двох кубиків.
2. Для кожного кидка зберігається сума чисел.
3. Підраховано частоту кожної суми й отримано емпіричну ймовірність.
4. Порівняно результати з аналітичними значеннями, відомими з комбінаторного аналізу.

## Висновки
- Метод Монте-Карло продемонстрував **високу точність** навіть для відносно невеликої кількості кидків (1 млн).
- Емпіричні ймовірності практично збігаються з теоретичними, що підтверджує **закон великих чисел**.
- Отриманий розподіл має форму **дзвону**, де найбільш імовірна сума — **7**.
- Метод Монте-Карло є ефективним інструментом для перевірки статистичних гіпотез і навчання принципам ймовірності.
